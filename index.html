Got Questions?

Frequently Asked Questions.

Do I need a paid Groq subscription to use Pragnya?

No! You can use completely free Groq API keys. Because Groq provides generous free-tier limits, you can add 2 to 5 free keys into Pragnya's Multi-Key Pool, enabling uninterrupted high-speed development without paying a single dollar.

How does the Multi-Key Auto-Failover feature work?

Pragnya maintains an internal active index of all your configured Groq API keys (1 compulsory, up to 4 backup). If your active key returns an HTTP 429 rate limit or token-per-minute ceiling, Pragnya intercepts the error and immediately retries the exact same request on the next available key without interrupting you.

Is my local desktop and code safe?

Yes. Pragnya enforces a strict Path Policy Sandbox. It only operates inside authorized working directories configured by you in Settings. Any destructive action (like file deletion or overwriting) is automatically recorded in a local SQLite audit database with rollback capability.

How do future updates work on other users' PCs?

Pragnya has a built-in GitHub Releases Auto-Updater. Simply click "🔄 Check for Updates" in Settings, and Pragnya will automatically query the repository, check if a newer release exists, download the binary, and upgrade in place.
