ENTERPRISE PRIVACY & SAFETY

Safe by Design. Zero Cloud Leakage.

Pragnya is engineered from the ground up for strict Windows security. You own your data, your files remain on your disk, and dangerous actions are never executed without your explicit permission.

1. Human-in-the-Loop Sandbox

All system mutations (deleting files, terminating processes, modifying critical directories) trigger an interactive PySide6 approval dialog.

  • Path traversal & symlink escape prevention
  • Dangerous command blacklists (format, rmdir /s)
  • Explicit user override modal with diff preview

2. Multi-Key Failover Pool

Never get stopped by Groq free-tier rate limits (HTTP 429). Store 1 to 5 API keys with instant round-robin failover and automatic retry.

  • Automatic key health monitoring
  • Seamless in-flight request retry on 429
  • Keys stored locally in OS user profile

3. Local-First SQLite Storage

Chat histories, DocuBrain document indexes, Watchdog rules, and invoice ledgers live inside local SQLite databases (agent.db).

  • SQLite FTS5 full-text BM25 index
  • Zero third-party cloud vector sync
  • 1-Click complete data export or wipe
